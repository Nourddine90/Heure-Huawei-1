# ساعة HUAWEI الرقمية ⏰

تطبيق ويب متطور لعرض الوقت والتاريخ بتصميم أنيق مستوحى من علامة HUAWEI.

## ✨ المميزات

- عرض الوقت الحالي بدقة الثانية
- عرض التاريخ الهجري/الميلادي
- تغيير الألوان تلقائياً حسب وقت اليوم
- عرض التوقيت العالمي (UTC)
- تصميم متجاوب يعمل على جميع الأجهزة
- واجهة مستخدم عصرية بتأثيرات بصرية
